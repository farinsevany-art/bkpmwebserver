SI AKADEMIK - ACARA 4

Struktur:
- app/Models/Mahasiswa.php: class Mahasiswa dengan property private dan getter.
- app/Views/partials/: header, navbar, footer.
- app/Views/layouts/main.php: layout utama.
- app/Views/mahasiswa/index.php: tabel Bootstrap.
- public/acara4 index.php: file sementara untuk membuat objek dan mengirim data ke View.

Cara pakai:
1. Ekstrak folder si-akademik-acara4 ke D:\xampp\htdocs\minngu1\si-akademik\
   atau salin isi folder hasil ekstrak ke folder proyek si-akademik yang sudah ada.
2. Pastikan struktur folder app dan public sesuai dengan daftar di atas.
3. Buka file public/acara4 index.php melalui cara yang biasa dipakai untuk menjalankan tugas di proyekmu.
4. Bootstrap memerlukan koneksi internet untuk memuat CSS/JS dari CDN.

Catatan:
- Class Mahasiswa hanya didefinisikan satu kali di app/Models/Mahasiswa.php.
- Tugas ini belum memakai Controller, sesuai instruksi membuat objek di index.php sementara.
- Tombol Tambah, Edit, dan Hapus masih tampilan contoh, belum memiliki fungsi CRUD.
